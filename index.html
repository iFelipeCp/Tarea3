Diseño web responsivo

Es una forma de diseñar páginas para que una misma página se adapte a cualquier tamaño de pantalla, ya sea celular, tablet o computadora, sin tener que hacer una versión distinta para cada uno.

Importancia

Hoy la mayoría de las personas navega desde el celular. Si una página no es responsiva, el texto se sale de la pantalla, hay que hacer zoom para leer y los botones quedan muy pequeños para tocarlos. Además, Google le da prioridad a las páginas que se ven bien en móviles.

Principios básicos

  • Medidas flexibles: usar porcentajes en vez de píxeles fijos.
  • Imágenes flexibles: que se achiquen con max-width: 100%.
  • Media Queries: cambiar el acomodo del contenido según el ancho de pantalla.
  • Mobile first: diseñar primero para celular y luego para pantallas grandes.

Viewport

Es el área visible de la página dentro del navegador. En una computadora es grande, pero en un celular es mucho más pequeña. Se configura con esta etiqueta dentro del <head>:

<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width: hace que el navegador use el ancho real del dispositivo en vez de simular una pantalla de escritorio.
  • initial-scale=1.0: evita que la página cargue con zoom.

Sin esta etiqueta, el celular muestra la página como si fuera de escritorio y todo se ve diminuto. Esta misma etiqueta está en el <head> de esta página.

CSS3 Media Queries

Aplican estilos diferentes según el tamaño de la pantalla. Se escribe una condición y los estilos dentro solo se usan cuando esa condición se cumple.

@media (max-width: 600px) {
  .mq-demo { background: orange; }
}
  • max-width: se aplica cuando la pantalla mide hasta ese ancho.
  • min-width: se aplica cuando la pantalla mide desde ese ancho.
  • orientation: según si el dispositivo está vertical u horizontal.

Ejemplo en vivo, achique la ventana del navegador a 600px o menos para ver el cambio:

Grid-View

Consiste en dividir la página en columnas, normalmente 12, para acomodar el contenido. Cada bloque ocupa cierta cantidad de columnas y, con Media Queries, esa cantidad cambia según la pantalla. Bootstrap 5

Es un framework gratuito de CSS y JavaScript que trae clases y componentes ya hechos para crear páginas responsivas más rápido. Para usarlo solo se agregan sus archivos desde internet (CDN): el CSS en el <head> y el JavaScript antes de cerrar el <body>.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Containers

.container centra el contenido y le da un ancho máximo que cambia según la pantalla. .container-fluid ocupa siempre todo el ancho. El fondo principal de esta página usa un container.
